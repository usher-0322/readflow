# 阅迹 Readflow

手机优先的本地阅读记录 PWA。支持多书并行计划、动态完成预测、计时与页数记录、独立摘抄流程、阅读统计、IndexedDB 持久化，以及 JSON 备份与恢复。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。手机测试时，可让手机和电脑处于同一网络，再使用 `npm run dev -- --host`。

## 构建与预览

```bash
npm run build
npm run preview
```

生产文件生成在 `dist/`。通过 HTTPS 部署后，浏览器可将应用安装到桌面/主屏幕；离线缓存会在首次访问后生效。

## 数据说明

- 所有数据默认保存在浏览器 IndexedDB 中，不上传服务器。
- 首次进入会生成演示数据，便于体验完整界面。
- 右上角设置提供 JSON 导入/导出。
- 清除站点数据会删除本地记录，请定期导出备份。
